# 深圳景田出发：周末两天一夜旅行候选方案

出发地：深圳福田景田天健天骄附近\
适用：周六日两天一夜情侣/朋友轻旅行\
交通优先考虑：地铁、高铁、飞机、自驾\
预算均按两人估算（普通舒适型，不含购物）

------------------------------------------------------------------------

# 一、海滨城市 / 夜景路线

## 1. 珠海 + 澳门（推荐★★★★★）

### 关键词

海边、夜景、情侣、慢节奏

### 交通

-   景田 → 蛇口邮轮中心 → 澳门
-   或 景田 → 深圳北 → 珠海高铁

### 主要景点

-   珠海情侣路
-   日月贝
-   澳门氹仔
-   威尼斯人
-   官也街
-   澳门夜景

### 预算

约 1000-2000 元 / 两人

------------------------------------------------------------------------

## 2. 厦门（推荐★★★★★）

### 关键词

海边、小资、拍照、美食

### 交通

-   深圳北 → 厦门北，高铁约3-4小时
-   或深圳宝安机场飞厦门

### 主要景点

-   鼓浪屿
-   中山路
-   沙坡尾
-   环岛路
-   曾厝垵
-   南普陀

### 预算

约 1500-2500 元 / 两人

------------------------------------------------------------------------

## 3. 惠州双月湾 / 巽寮湾（推荐★★★★）

### 关键词

近距离海边、轻松度假

### 交通

-   自驾最佳
-   高铁到惠东后转车

### 景点

-   双月湾观景台
-   海边日落
-   沙滩

### 预算

约 800-1500 元 / 两人

------------------------------------------------------------------------

# 二、广东省内文化、美食路线

## 4. 潮州 + 汕头（推荐★★★★）

### 关键词

美食、古城、慢旅行

### 交通

深圳北 → 潮汕站 约2小时

### 景点

潮州： - 广济桥 - 牌坊街 - 韩文公祠

汕头： - 小公园 - 老城区 - 牛肉火锅

### 预算

约 1000-1600 元 / 两人

------------------------------------------------------------------------

## 5. 广州周末游（推荐★★★）

### 关键词

城市、美食、购物

### 景点

-   珠江夜游
-   广州塔
-   沙面
-   永庆坊
-   北京路

### 交通

深圳 → 广州南 高铁约30分钟

### 预算

约600-1200元

------------------------------------------------------------------------

## 11. 张家界（推荐★★★★★）

# 八、推荐优先级总结

## 情侣周末最佳

1.  珠海澳门
2.  厦门
3.  桂林阳朔
4.  潮州汕头
5.  平潭岛

## 性价比最高

1.  珠海
2.  潮汕
3.  佛山顺德
4.  广州

## 自然风景最好

1.  桂林阳朔
2.  张家界
3.  平潭岛

## 不想太累

1.  珠海澳门
2.  广州
3.  顺德
4.  惠州
