# 深圳景田天健天骄出发：桂林阳朔两天一夜详细攻略

## 一、旅行条件

-   出发地点：深圳福田景田天健天骄附近
-   人数：2人（情侣参考）
-   时间：周六日
-   周六出发：不早于08:30
-   周日返回：21:00前回到深圳景田天健天骄
-   旅行特点：
    -   山水风景
    -   漓江
    -   阳朔骑行
    -   适合情侣拍照

------------------------------------------------------------------------

# 二、总体推荐

## 推荐交通：高铁

原因：

-   深圳到桂林高铁方便
-   比飞机更稳定
-   不需要提前大量时间到机场
-   周末两天可以完成经典路线

主要路线：

深圳北 → 桂林西

然后：

桂林西 → 桂林市区 → 阳朔

------------------------------------------------------------------------

# 三、交通详细规划

# 四、Day 1 行程

## 13:00 - 14:00

抵达桂林西。

前往桂林市区午餐。

交通：

-   打车约30分钟
-   费用约40-60元

------------------------------------------------------------------------

# 14:00 - 16:30

桂林市区游览

推荐：

## 象鼻山

特点：

-   桂林代表景点
-   时间成本低

游览：

约1小时

------------------------------------------------------------------------

## 两江四湖

推荐：

下午或者傍晚。

适合：

-   散步
-   拍照

------------------------------------------------------------------------

# 16:30 - 18:00

前往阳朔。

方式：

## 高铁

桂林西/桂林站 → 阳朔站

或者：

## 打车/顺风车

桂林市区 → 阳朔西街

约1小时。

建议：

如果两个人，直接打车更省时间。

费用：

约100-150元。

------------------------------------------------------------------------

# 18:00 - 21:00

阳朔晚间路线

## 西街

体验：

-   夜景
-   小吃
-   酒吧街

------------------------------------------------------------------------

推荐：

晚上不要安排太累。

可以：

-   漫步西街
-   看漓江夜景

------------------------------------------------------------------------

-   晚上热闹

400-700元

------------------------------------------------------------------------

### 2. 遇龙河附近

-   风景更好
-   适合情侣

预算：

500-900元

# 八、天气要求

桂林阳朔非常看天气。

最佳：

-   晴天
-   多云

可以接受：

-   小雨

雨天特点：

优点： - 山水有雾气 - 更有意境

缺点： - 竹筏体验下降

不建议：

-   暴雨
-   台风天气
