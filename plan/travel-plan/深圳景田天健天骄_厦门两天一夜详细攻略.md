# 深圳景田天健天骄出发：厦门两天一夜情侣旅行详细攻略

## 一、旅行条件

-   出发地点：深圳福田区景田天健天骄附近
-   人数：2人（情侣参考）
-   时间：周六日
-   周六出发时间：不早于 08:30
-   周日返程要求：21:00 前回到深圳景田天健天骄
-   旅行风格：
    -   海边
    -   城市漫步
    -   拍照
    -   美食
    -   不赶行程

------------------------------------------------------------------------

# 二、总体推荐方案

## 推荐交通：高铁

原因： - 深圳到厦门距离适中 - 高铁比飞机实际耗时更稳定 -
深圳北交通方便 - 不需要提前很久到机场

## 预计时间

深圳北 → 厦门北：

-   时间：约 3.5 小时
-   单程：约 200-250 元/人

------------------------------------------------------------------------

# 三、交通详细规划

## 周六出发

### 08:30 - 09:15

景田天健天骄 → 深圳北站

推荐：

方案1：地铁

预计： - 景田站附近 → 深圳北 - 时间约40分钟

方案2：打车

预计： - 时间30-40分钟 - 费用约40-60元

建议： 如果带行李，直接打车。

------------------------------------------------------------------------

## 09:30 - 10:00

深圳北候车

建议提前：

-   买早餐
-   上厕所
-   准备饮料

------------------------------------------------------------------------

## 10:00左右

深圳北 → 厦门北

高铁：

预计： - 3-3.5小时

------------------------------------------------------------------------

# 四、Day 1 行程

## 13:30 - 14:30

抵达厦门北

前往酒店。

推荐住宿区域：

## 第一选择：思明区

优势： - 景点集中 - 晚上方便 - 不需要频繁打车

推荐区域：

-   中山路
-   沙坡尾
-   厦大附近
-   曾厝垵附近

预算：

普通舒适酒店： 400-700元/晚

------------------------------------------------------------------------

# 14:30 - 15:30 午餐

推荐方向：

## 八市附近

体验：

-   海鲜
-   闽南小吃
-   沙茶面

预算：

两人： 80-150元

------------------------------------------------------------------------

# 15:30 - 17:30 鼓浪屿

推荐：

厦门旅行最经典路线。

交通：

思明区 → 厦鼓码头

船程： 约20分钟

建议：

提前购买船票。

游览：

-   日光岩附近
-   最美转角
-   海边步道
-   老建筑

预计：

2小时左右。

------------------------------------------------------------------------

# 17:30 - 19:00 沙坡尾

推荐原因：

-   年轻化
-   拍照好看
-   傍晚氛围好

可以：

-   逛街
-   咖啡店
-   拍照

------------------------------------------------------------------------

# 19:00 - 21:00 环岛路夜景

路线：

沙坡尾 ↓ 白城沙滩 ↓ 环岛路

适合：

-   看海
-   散步
-   情侣聊天

------------------------------------------------------------------------

# 21:00 返回酒店

晚上可以：

-   中山路步行街
-   曾厝垵夜市

------------------------------------------------------------------------

# 五、Day 2 行程

下午开始返程，保证21点前回深圳。

------------------------------------------------------------------------

# 16:30左右

# 20:00 - 20:30

预计：
