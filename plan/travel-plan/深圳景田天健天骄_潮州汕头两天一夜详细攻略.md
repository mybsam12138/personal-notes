# 深圳景田天健天骄出发：潮州 + 汕头两天一夜详细攻略

## 一、旅行条件

-   出发地点：深圳福田区景田天健天骄附近
-   人数：2人（情侣参考）
-   时间：周六日
-   周六出发：不早于08:30
-   周日返回：21:00前回到深圳景田天健天骄
-   旅行特点：
    -   潮汕美食
    -   古城文化
    -   老城区漫步
    -   适合轻松周末

------------------------------------------------------------------------

# 二、总体推荐

## 推荐路线

深圳 → 潮州 → 汕头 → 深圳

原因：

-   距离近
-   高铁方便
-   不需要赶飞机
-   两天一夜刚好

------------------------------------------------------------------------
