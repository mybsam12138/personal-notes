# 深圳景田天健天骄出发：惠州双月湾两天一夜详细攻略

## 一、旅行条件

-   出发地点：深圳福田区景田天健天骄附近
-   人数：2人（情侣参考）
-   时间：周六日
-   周六出发：不早于08:30
-   周日返回：21:00前回到深圳景田天健天骄
-   旅行特点：
    -   海边度假
    -   看日落日出
    -   沙滩散步
    -   节奏轻松

------------------------------------------------------------------------

# 二、总体推荐

双月湾适合：

-   不想坐高铁
-   不想赶景点
-   想住海边酒店
-   周末放松

相比珠海： - 海更自然 - 沙滩更开阔

相比厦门： - 旅游设施较少 - 但更适合短途度假

------------------------------------------------------------------------

# 三、交通方案

## 推荐：自驾

原因：

-   双月湾公共交通不方便
-   景点之间距离较远
-   带行李更舒服

------------------------------------------------------------------------

# 九、天气要求

双月湾非常看天气。

最佳：

-   晴天
-   多云

适合：

-   小雨但不影响住宿

不推荐：

-   台风
-   大风
-   连续暴雨

原因：

-   海边活动减少
-   海景体验下降

------------------------------------------------------------------------
