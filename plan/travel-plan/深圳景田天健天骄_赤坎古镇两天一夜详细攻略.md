# 深圳景田天健天骄出发：江门开平赤坎古镇两天一夜详细攻略

## 一、旅行条件

-   出发地点：深圳福田区景田天健天骄附近
-   人数：2人（情侣参考）
-   时间：周六日
-   周六出发：不早于08:30
-   周日返回：21:00前回到深圳景田天健天骄
-   类型：
    -   古镇漫步
    -   侨乡建筑
    -   岭南文化
    -   夜景拍照
    -   轻松旅行

------------------------------------------------------------------------

# 二、目的地介绍

## 赤坎古镇（开平）

赤坎古镇位于广东江门开平，是典型的岭南侨乡古镇。

特点：

-   骑楼建筑群
-   华侨文化
-   影视取景地
-   夜景适合拍照
-   节奏慢，适合周末

适合人群：

-   情侣散步
-   喜欢历史建筑
-   喜欢拍照

------------------------------------------------------------------------

# 三、交通方案

## 方案A：自驾（推荐）

原因：

赤坎古镇周边还有：

-   开平碉楼
-   自力村
-   立园

如果只去古镇，自驾仍然最方便。

------------------------------------------------------------------------

## 周六交通

### 08:30

景田天健天骄出发。

路线：

深圳福田 → 广深高速 → 沈海高速 → 开平赤坎

------------------------------------------------------------------------

预计：

车程： 约2.5-3小时

距离： 约180公里

费用：

油费+高速：

约250-350元（往返）

------------------------------------------------------------------------

## 方案B：高铁+打车

路线：

景田 → 深圳北

深圳北 → 江门站

时间：

约1小时左右

然后：

江门站 → 赤坎古镇

车程：

约50-70分钟

打车：

约120-180元

缺点：

古镇周边交通不如自驾方便。

------------------------------------------------------------------------
